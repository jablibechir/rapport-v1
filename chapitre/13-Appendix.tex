{\Large\bfseries Résumé}
\vspace{0.4cm}
\end{center}

\noindent Ce projet de fin d'études porte sur la conception et le développement d'un portail de recrutement intelligent destiné à Sopra HR Software. La plateforme Sopra Recruit centralise le processus de recrutement avec la gestion des offres d'emploi, le suivi des candidatures, l'analyse automatique des CV par IA, le scoring des candidats et la planification des entretiens. Le développement suit la méthodologie Agile Scrum en quatre sprints. Les technologies utilisées sont Spring Boot, React, PostgreSQL et Python.

\vspace{0.3cm}
\noindent\textbf{Mots-clés :} Recrutement intelligent, Portail web, IA, Analyse de CV, Scoring, Spring Boot, React, Scrum.

\vspace{1cm}

\begin{center}
{\Large\bfseries Abstract}
\vspace{0.4cm}
\end{center}

\noindent This project is about building a smart recruitment website for Sopra HR Software. The platform is called Sopra Recruit. It helps the company manage job offers, track applications, and analyze CVs using artificial intelligence. The system gives each candidate a score and helps HR plan interviews. We built this project using the Agile Scrum method in four sprints. We used Spring Boot for the server, React for the website, PostgreSQL for the database, and Python for the AI part.

\vspace{0.3cm}
\noindent\textbf{Keywords:} Smart recruitment, Web portal, AI, CV analysis, Scoring, Spring Boot, React, Scrum.
